je dois sécuriser l'app : 1. Sécuriser les API avec FastAPI (Le Backend)FastAPI intègre nativement
 des outils performants pour verrouiller vos points d'accès :Authentification : Utilisez le protocole
  OAuth2 avec des jetons JWT (JSON Web Tokens) éphémères (durée de vie de 15 minutes) pour 
  authentifier les utilisateurs RH.Contrôle des rôles (RBAC) : Utilisez les dépendances de
   FastAPI (Depends) pour vérifier le rôle de l'utilisateur avant d'exécuter 
   une fonction d'IA (ex: verify_admin_role).CORS (Cross-Origin Resource Sharing) : 
   Configurez le middleware CORS de FastAPI pour autoriser uniquement l'adresse IP ou le 
   domaine de votre application TypeScript à interroger le backend.2. Le Pipeline de Sécurité IA 
   en PythonPuisque vous êtes sur FastAPI, vous pouvez intégrer la sécurité de l'IA directement 
   sous forme de middlewares ou de services Python avant d'appeler votre modèle local (Ollama/vLLM) 
   :Anonymisation : Installez pip install presidio-analyzer presidio-anonymizer. Créez une fonction FastAPI qui 
   filtre le texte envoyé par l'utilisateur TypeScript pour masquer les données nominatives.Validation du 
   Prompt : Utilisez la bibliothèque pydantic de FastAPI pour forcer la structure des données 
   entrantes et empêcher l'injection de scripts malveillants.3. Sécuriser le Frontend (TypeScript)TypeScript 
   vous aide à éviter les erreurs de manipulation de données sensibles côté client :Typage strict des données RH 
   : Créez des interfaces TypeScript strictes pour les données d'employés. Ne transmettez jamais d'objets "any".
    Masquez les champs sensibles côté client dès la réception.Stockage sécurisé : Ne stockez jamais le jeton JWT 
    dans le localStorage (vulnérable aux failles XSS). Stockez-le en mémoire ou dans un cookie sécurisé 
    HttpOnly et Secure.
